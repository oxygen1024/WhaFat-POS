## POS 資料結構

`dist/data/catalog.json`：

- 頂層：`schemaVersion: 1`、`sourceUrl`、`currency: "HKD"`、`importedAt`、`products`、`collections`、`summary`。
- 商品：保留來源 `id`、`handle`、`title`、`vendor`、`productType`、`tags`、`sourceUrl`、`images`、`options`、`variants`，另有 `collectionIds`、`sourceUpdatedAt`。
- 款式：來源 `id`、`title`、`sku`、`barcode`、`priceCents`、`compareAtPriceCents`、`available`、`option1/2/3`、`imageUrl`。缺少的 SKU／條碼保持 `null` 或來源空字串；未建立虛構貨號。
- 可選款式欄位 `priceReviewReason`：19 個零元價格標示「網站價格為 HK$0，需人工確認」；上述五款指定 ID 且價格仍為 HK$11,111 時標示「網站價格疑似佔位值 HK$11,111，需人工確認」。正常款式不包含此欄位。這項提示不修改來源售價。
- 圖片：`{id, src, alt}`。款式優先使用該款式圖片，沒有指定款式圖才使用該商品第一張圖片；商品完全沒有圖片時為 `null`。
- 分類：`{id, title, handle, sourceUrl, productIds, productCount}`；一個商品可以有多個分類。
- 來源 ID 為數值，當前全部低於 JavaScript 安全整數上限。介面若用字串選單值，應以 `String(id)` 比較。
- 售價以十進位方式轉換成整數「仙」，例如 `"226.00" → 22600`，沒有浮點四捨五入。比較價格為未提供時 `null`，不替代現價。

## 再次匯入

在專案資料夾執行：

```sh
python3 scripts/import_catalog.py
```

從既有快照驗證，不向網站發送請求：

```sh
python3 scripts/import_catalog.py --snapshot data/source/20261020T091110Z --output /tmp/wahfat-catalog-replay.json
```

匯入器使用系統 `curl` 的正常 TLS 憑證驗證，沒有停用安全驗證。更新不會改動原站的價格、商品、訂單或庫存。

## 使用界線

現階段只有公開商品快照：沒有驗證店內實際庫存、採購成本、條碼對應、付款設備、收據打印機或 Shopify 訂單同步。圖片需要原站 CDN 可連線；不能保證所有圖片在離線環境仍可顯示。正式部署需要店方確認商品資料和圖片的使用授權，並決定是否改用經授權的 Shopify 後台同步。
